## Implemented contract

- Launch opens the trusted workspace, store, registry, and OS randomness,
  installs SIGINT/SIGTERM interception before any `tcsetattr`, then performs a
  Linux `/dev/tty` rustix termios preflight before binding exactly `127.0.0.1`.
  Non-Linux and non-controlling-TTY launches fail closed. Output contains only
  the clean loopback URL and non-secret instructions.
- The browser generates exactly eight bytes with `crypto.getRandomValues`,
  registers one strict lowercase code, immediately starts one bounded exchange,
  clears visible code text on every exchange outcome, and retains the distinct
  32-byte session only in its current closure. The former fragment and Web
  Storage code is removed. End Session clears the closure token only after a
  confirmed authenticated revocation. A failed/unconfirmed revoke retains the
  token, disables consequential actions, and instructs retry or console stop.
- The in-memory authority binds a random 128-bit instance ID and canonical
  workspace, implements terminal bootstrap states and session states, uses
  monotonic 120/900/300-second deadlines with equality expired, fixed-work
  decoded-byte comparisons, one claimed waiter preserved across Pending to
  Verified, both exchange-before-verify and verify-before-exchange orderings,
  consumed-before-response exchange, explicit revoke, and fail-closed
  poisoned/randomness state. Global shutdown terminalizes even an absent
  bootstrap, wakes its waiter, and prevents the terminal-task join from hanging
  when SIGINT/SIGTERM/server failure occurs before the browser registers.
- The termios guard disables echo for one bytewise terminal attempt, accepts
  only exact 16-hex or displayed 4-4-4-4 input, treats byte `0x04` as terminal
  loss, explicitly restores and re-reads all original attributes before any
  verification status is published, and uses Drop only as fallback. Every
  bind/server/signal/select outcome revokes authority, joins terminal handling,
  and verifies restoration. No password helper, `stty`, browser launcher, or
  credential-bearing child argument/environment was added.
- Every API request passes exact single Host middleware. Every POST also passes
  exact single Origin and JSON content type before routing/body parsing.
  Bootstrap, exchange, revoke, and decision parse raw bytes into strict JSON
  and map malformed/unknown/duplicate input to fixed generic JSON. Approval
  paths are parsed from the raw URI after session authentication, avoiding
  framework path-rejection detail. Generated and handler errors receive
  no-store/nosniff and no CORS and never reflect sentinel-bearing input.
- One authority mutex lease spans final mutation authentication, fresh registry
  load and immediate HumanOnly check, complete actionable-context reload,
  enrolled/sealed Human selection, key access, signing, and durable decision.
  Revoke and expiry serialize on the same mutex. Existing v1/v2 review,
  approve/deny, one-decision, no execution, and no generic live-v2 resume remain.
