# E0006-07 Handoff

Status: done and quiescent — credential-free launcher-first diagnostic PASS

## Result

The isolated-browser blocker is operationally reproduced and bounded. Installed
`agent-browser 0.19.0` rejects `open about:blank` because `open` requires a URL
with a hostname. Chrome then leaves the new isolated target on its privileged
New Tab document. The failed D-E0006-015 ceremony attempted asynchronous
navigation from that document, while the Human separately opened the product
URL in a regular browser; those contexts could not satisfy same-tab evidence.

A credential-free launcher-first probe established the deterministic path:

1. start one isolated headed named session and navigate its only tab to a fast
   loopback launcher document;
2. accept an `agent-browser open` `Page.navigate` timeout only after direct URL,
   title, body, console, overlay, snapshot, and visual checks prove that the
   launcher is the live document;
3. asynchronously call `location.assign` from that ordinary HTTP document to
   the target; and
4. treat direct current-document reads as authoritative while tab inventory may
   retain its initialization label.

## Evidence

- The launcher directly reported URL `http://127.0.0.1:43125/launcher`, title
  `E0006 attachment launcher`, meaningful launcher text, no error overlay, and
  one visible button. Console inspection was clean and a credential-free visual
  check matched the snapshot.
- The same existing document scheduled navigation to `/target`. Direct reads
  then reported URL `http://127.0.0.1:43125/target`, title
  `E0006 attachment target`, marker `Credential-free single-tab attachment
  probe`, state `pending`, and no error overlay. Console inspection and the
  credential-free visual check were clean.
- Tab inventory remained exactly one tab but labeled it `New Tab -
  chrome://newtab/`. That metadata was stale; direct URL/title/body/state reads
  consistently reached the live target.
- No product workspace, approval UI, bootstrap/session, Human handoff, decision,
  provider, execution, or external effect was created.

## Cleanup

The exact isolated browser session was closed. The fixed IPv4-loopback listener
on `127.0.0.1:43125` was stopped and listener absence confirmed. The exact
transient probe and browser-runtime directories, including both credential-free
screenshots, were permanently removed and are not recoverable.

## Recommendation and remaining gate

Any future E0006 product ceremony must initialize and independently verify the
credential-free launcher before creating the time-boxed product fixture. It
must then navigate that already-visible headed tab asynchronously to the clean
product URL, and the Human must use that same headed window rather than opening
the URL in a regular browser. Both orchestrator and verifier must establish the
product document through direct reads before terminal handoff; inventory labels
remain non-authoritative.

This diagnostic is not product evidence and does not authorize another

without a new explicit product-owner authorization. D-E0006-018 subsequently
