## UX and safety invariants

- The initial click selects an outcome but cannot send a decision.
- The confirmation region binds visible outcome, exact operation/version, and
  exact request ID to an immutable in-memory snapshot of request, outcome,
  approver, and reason.
- The final action begins disabled and uses exact string equality; whitespace,
  case, request, or outcome differences remain disabled.
- There is no form, native confirmation dialog, Enter handler, or default-submit
  path. The final button is `type="button"`, and Enter is explicitly suppressed
  on both the challenge input and final button.
- Inbox rows and approver/reason controls remain disabled while intent,
  preflight, or decision submission is pending. Cancel remains available during
  the preflight so it can invalidate the captured object before any decision
  POST.
- Final submission first performs a protected detail GET and re-checks the
  frozen object, current selection/form values, exact operation, enrolled
  approver, actionability, and local request deadline. Any known mismatch or
  failure clears the intent without a decision POST.
- The unchanged backend mutation authority lease remains authoritative for the
  unavoidable race after the fresh detail check. A lost response after the POST
  begins is reported as uncertain and directs the Human to review the inbox;
  the UI does not claim that no request was sent.
- End Session clears pending intent before requesting revoke. Reload/navigation
  loses both intent and session because neither is stored outside the current
  JavaScript closure.

## Risks and residual work

  new authority boundary. Server session validation, fresh actionability,
  Human-key selection, signing, and one-decision persistence remain decisive.

  the unchanged backend mutation lease rejects it or linearizes the one valid
  decision. The browser guard does not weaken or replace that boundary.

  sequence from redacted evidence. This patch closes the authorized accidental
  wrong-outcome UI class prospectively.
