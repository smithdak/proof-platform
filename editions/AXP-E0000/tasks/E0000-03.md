# E0000-03 — Swarm launcher ownership checks

Model: `gpt-5.6-terra` · reasoning: `medium`

## Objective

Make the swarm launcher enforce one writer per path, show a root-plus-three-
worker assignment and handoff status, and print a self-contained dispatch
packet for an assigned worker.

## Writable paths (exclusive)

- `scripts/swarm.sh`
- `scripts/swarm-fixtures/**`
- `editions/AXP-E0000/handoffs/E0000-03.md`

## Read-only references

`AGENTS.md`, `editions/AXP-E0000/workgraph.md`, `editions/AXP-E0000/ownership.md`,
existing `scripts/**`.

## Dependencies

E0000-01.

## Risk and owner gate

Medium; orchestrator reviews shell safety and compatibility before use.

## Non-goals

Do not change agent runtime, Git history, root manifests, or launch external
agents. Do not alter another script.

## Acceptance

1. `rtk shellcheck scripts/swarm.sh` passes if shellcheck is available.
2. `rtk bash -n scripts/swarm.sh` passes.
3. `rtk scripts/swarm.sh --help` documents tracked edition commands.
4. `rtk scripts/swarm.sh validate AXP-E0000` passes.
5. `rtk scripts/swarm.sh packet AXP-E0000 E0000-04` prints the assignment
   metadata and exact task packet.
6. `rtk scripts/swarm.sh validate-assignments scripts/swarm-fixtures/assignments-valid.tsv` passes.
7. `rtk scripts/swarm.sh validate-assignments scripts/swarm-fixtures/assignments-overlap.tsv` fails with an ownership-overlap message.
8. `rtk scripts/swarm.sh validate-assignments scripts/swarm-fixtures/assignments-forward-dependency.tsv` fails with a forward-wave dependency message.
9. `rtk git diff --check -- scripts/swarm.sh scripts/swarm-fixtures editions/AXP-E0000/handoffs/E0000-03.md` passes.

## Stop/escalate

Stop on destructive Git commands, implicit `git add -A`, or ambiguous ownership;
escalate the proposed interface to the orchestrator.

## Handoff schema

Report: script paths; dry-run examples; overlap rejection result; shell checks;
assumptions; risks; follow-up requests.
