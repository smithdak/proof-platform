   current sorted objects with the v1 SHA-256 content digest, persists the
   immutable Edition, and returns the exact `{operation,data.edition}` shape.

   once, an exact canonical retry returns identical output and original proof
   ID/body/signature, and same-key changed input conflicts before mutation.
   Missing/non-v7 keys, absent/unsupported storage, and handler failure remain
   fail-closed.
