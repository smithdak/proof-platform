# E0000-02 — `.proof` security remediation

Model: `gpt-5.6-sol` · reasoning: `high`

## Objective

Assess and prepare owner-approved remediation for tracked `.proof` key/config/
database material. Treat keys as potentially compromised. Preserve files and do
not expose, print, copy, decode, or read key contents.

## Writable paths (exclusive)

- `.gitignore`
- `.proof/**` metadata, tracking state, or owner-approved replacement only;
  never key contents
- `editions/AXP-E0000/handoffs/E0000-02.md`

## Read-only references

`AGENTS.md`, `editions/AXP-E0000/charter.md`,
`editions/AXP-E0000/decisions.md`, `git ls-files`, file metadata only.

## Dependencies

E0000-01. Owner approval is required before untracking, rotation, quarantine,
history rewrite, notification, or any action changing key state.

## Risk and owner gate

P0/critical. No remediation action beyond safe metadata inspection may happen
without explicit product-owner approval recorded in decisions.md.

## Non-goals

Never run commands that cat, hash, archive, upload, or display private key
contents. Do not delete files, rewrite history, contact providers, or rotate
credentials autonomously.

## Acceptance

1. `rtk git ls-files .proof` identifies tracked paths without reading contents.
2. `rtk stat -c '%a %n' .proof/config.json .proof/keypair.json .proof/storage/storage.db` records permissions and path names only.
3. `rtk git diff --check -- .gitignore editions/AXP-E0000/handoffs/E0000-02.md` passes.
4. Owner approval and chosen action are recorded before any untracking/rotation.

## Stop/escalate

Stop immediately on any request to expose key material, or before any state-
changing security action lacking owner approval. Escalate exact action, scope,
and recovery plan.

## Handoff schema

Report: paths identified (names only); metadata findings; owner decision ID;
actions taken/not taken; evidence locations; residual exposure; next approval.
