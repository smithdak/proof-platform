## Acceptance

1. `rtk cargo fmt --check -p proof-transport-cli` passes.
2. `rtk cargo test -p proof-transport-cli` passes.
3. CLI integration tests prove both operations dispatch through the engine and
   return/persist version-bound signed evidence.
4. The governed path uses the engine's evidenced outcome and does not mint a
   transport-local replacement proof. The engine uses the workspace keypair
   and durable store; the returned original proof is written idempotently to
   the CLI's existing proof-file view so status/verify remain compatible.
5. An exact retry returns identical output and the original proof ID, body, and
   signature without a second mutation; changed input under the same key
   conflicts before mutation.
6. Direct `edition.create` and `changeset.commit` commands accept a
   caller-controlled UUIDv7 key so retries are possible. The local
   `changeset.create` helper creates no governed proof and is not registered as
   a ninth operation.
