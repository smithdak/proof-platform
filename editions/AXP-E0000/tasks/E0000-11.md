## Acceptance

1. `rtk cargo fmt --check -p proof-transport-http` passes.
2. `rtk cargo test -p proof-transport-http` passes.
3. Tower oneshot tests cover both operations' capability discovery, execution,
   error mapping, and version-bound proof response.
4. The HTTP engine is attached to its durable store and returns
   `execute_evidenced`'s outcome instead of minting a transport-local proof.
   It is built with the same keypair used by request contexts and registers the

   signature without a second mutation; changed input under the same key maps
   to 409 before mutation.
6. The pre-existing canonical mappings are enforced: delegation failures are
   403 and expired benchmark evidence is 409, with focused tests.
7. The existing HTTP workspace database path is retained in E0000; the handoff
   records that HTTP/WS and CLI/MCP path unification needs a separately gated
   compatibility/migration decision.
