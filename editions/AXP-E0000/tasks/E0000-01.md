# E0000-01 — Edition records

Model: `gpt-5.6-luna` · reasoning: `low`

## Objective

Establish the tracked edition-record protocol so a cheap agent can create,
update, and hand off bounded waves without chat-only state.

## Writable paths (exclusive)

- `editions/AXP-E0000/**`
- `editions/BACKLOG.md`

## Read-only references

`AGENTS.md`, `ARCHITECTURE.md`, `editions/README.md`,
`editions/_template/**`, `editions/AXP-E0000/charter.md`.

## Dependencies

None. This must close before all other E0000 packets.

## Risk and owner gate

Low product risk; orchestrator review required before records are used as an
assignment source.

## Non-goals

Do not edit Rust, scripts, contracts, secrets, `.proof`, or historical records.

## Acceptance

1. `rtk rg --files editions/AXP-E0000` lists charter, workgraph, ownership,
   status, decisions, evidence, retro, assignments, task packets, and handoffs.
2. `rtk scripts/swarm.sh validate AXP-E0000` passes.
3. `rtk git diff --check -- editions` passes.
4. `rtk git status --short -- editions` shows only intended edition files.

## Stop/escalate

Stop if a required record already has another writer or if scope requires code;
escalate to the orchestrator with the path and requested decision.

## Handoff schema

Report: files changed; commands/results; record protocol decisions; assumptions;
risks; unresolved requests; recommended next packet.
