verification, and present an owner-ready release decision.

High. Product owner must approve release, defer with rationale, or reject; agent
cannot self-approve the edition.

## Non-goals

Do not repair another worker's implementation, run destructive Git commands, or
silently waive failed acceptance checks.

## Acceptance

1. `rtk git diff --check -- editions/AXP-E0000 editions/BACKLOG.md` passes.
2. `rtk git status --short` is reviewed for unrelated changes.
3. Run each changed-package impact command from handoffs.
4. `rtk scripts/swarm.sh verify AXP-E0000 --quiescent` passes; this charter
   explicitly authorizes the orchestrator-only final workspace gate after all
   writers stop.
5. Evidence register has a result for every item and owner decision is recorded.

## Stop/escalate

Stop on missing evidence, dirty unrelated changes, failed security gate, or
unresolved contract conflict. Escalate with a bounded repair plan.

## Handoff schema

Report: integrated revision; scoped commands/results; evidence index; open risks;
owner decision request; release/defer/reject recommendation; retro inputs.
