## Gate B resolution applied

Owner decision D-E0000-005 approved all three proposals on 2026-08-29:

1. **Target-operation v1 input/output and replay contract.** The contract now
   requires an explicit UUIDv7 `idempotency_key` in both inputs, bound to the
   canonical input digest; identical key+input returns the original persisted
   output/proof, and reused key+different input fails. Outputs use the envelope
   `{operation,data}` with `data.changeset` containing the actual serialized
   committed `ChangeSet` plus `objects_count`, and `data.edition` containing the
   serialized immutable `Edition`.
2. **`changeset.create` compatibility disposition.** The contract keeps the
   frozen eight governed operations. Preserve a local authoring helper only if
   useful, but stop it from minting a proof for an unregistered ninth operation.
   Adding `changeset.create` to the registry/domain contract remains outside
   E0000.
3. **Digest scope.** Architecture D7 now applies BLAKE3-256 to kernel evidence;
   existing content snapshot identifiers remain SHA-256 for v1. Migration is
   deferred to an explicitly versioned later contract.
