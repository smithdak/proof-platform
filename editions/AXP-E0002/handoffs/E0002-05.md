## Exact implementation

- Added only the barrier-approved kernel dependencies: `sha2.workspace = true`,
  `subtle.workspace = true`, and `zeroize.workspace = true`. No Cargo command
  ran before the auth owner reported `W3 lock stable`.
- Added the frozen operator common/durable/store types, closed enums, signer and
  store traits, deterministic environment seam, recording environment/store,
  raw-artifact SHA-256 and constant-work 32-byte comparison helpers, and public
  re-exports. No `ExecutionError` variant was added.
- `LeaseTokenCustody` and `DispatchTokenCustody` now start from only a
  zeroizing raw token, issue one opaque establishment/authorization borrow,
  bind the exact store-produced lease/fence or dispatch permit tuple, and are
  consumed into one release, commit, or failure request. Secret-bearing
  requests are nonserializing; `BeginDispatchRequest` exposes no raw token.
- Added the opaque, non-cloneable, non-debug, nonserializing
  `GovernedAdapterReporter`. Governed registration mints exactly one reporter
  for the selected factory and stores immutable operation/version/kind/adapter/
  model metadata with the exact handler. Ordinary registration is governed-
  ineligible. `PreparedBoundaryUsage`, `PreparedHandlerOutput`, and sealed
  `PreparedUsage` have private fields and no deserialization or request path.
  `PreparedUsageRecord` is a separate untrusted persisted projection and cannot
  construct sealed usage.
- `execute_evidenced_unpersisted` remains storage-free and checks actor,
  delegation membership/terminal recipient/scope, catalog input, canonical
  argument/intent/call identities, exact run/step/checkpoint/replay/permit
  identities and branches, immutable registration metadata, status/nullability,
  chronology, trusted UTC, monotonic deadline, and one-use custody immediately
  before the single handler entry. It validates the sealed report branch,
  values, adapter/model, output schema, and ceiling before preparing evidence.
- Added exact `RecoveryDirective.classification`, settlement disposition and
  outcome, `CursorClaims`, replay policy, recovery disposition, runtime failure
  classification, prepared mutation, and control-transition outcome/proof-
  operation enums. The proof-operation wires are exactly
  `operator.approval_decide`, `operator.run_cancel`, `operator.run_resume`, and
  `operator.session_revoke`.
- Added validation for four run-projection branches, cancel/idempotent receipts,
  cursor/scope binding and ordering, lease/reclaim/dispatch custody, budget and
  reservation state profiles, replay result branches, prepared/runtime result
  projections, recovery ties, revision/status/chronology/digest invariants, and
  every audit transition presence mask.
- Added strict serde adapters for canonical lowercase-hyphenated UUIDv7 with
  RFC4122/RFC9562 variant, optional UUIDv7, principals, exact `Z` UTC timestamps
  with non-leap seconds and 1-9 fractional digits, and JSON safe integers.
  Serialization rejects invalid typed values as well as deserialization
  rejecting normalized spellings, wrong variants, offsets, leap seconds, and
  expanded years. These adapters cover every direct E0002 UUID/time/safe-
  integer DTO field and nested prepared-result projection.
- `OperatorSchemaCatalog` requires the exact Draft 2020-12 declaration and
  canonical operation/version syntax before validator compilation, rejects
  duplicate JSON names and every non-fragment schema reference, validates its
  closed source inventory, and computes artifact digests from exact supplied
  raw bytes.
