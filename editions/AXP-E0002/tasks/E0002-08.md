## Acceptance

- Independent volatile sessions bind exact Human/workspace/instance plus only
  the granted `run.read`, `approval.read`, `approval.decide`, `run.cancel`,
  `run.resume`, and `audit.read` capabilities.
- Issuance verifies a one-use signed nonce bound to instance, workspace,
  requested capabilities, and expiry; grants only the intersection allowed by
  workspace policy; replay, downgrade/confusion, and self-escalation fail.
- Missing, malformed, duplicate, expired, revoked, cross-Human, cross-workspace,
  cross-instance, and cross-capability credentials fail in constant work before
  protected data/key/write callbacks.
- Deterministic barriers prove exactly one authorize/revoke/expiry race winner,
  no protected callback after lost authority, memory loss/restart invalidation,
  and explicit self-revoke behavior.
- Auth accepts the kernel environment trait and derives every live deadline,
  nonce, token, and UUID internally; tests inject fixed time/seeded entropy,
  while request DTOs expose none of those sources.
- No credential appears in URL, argv, ordinary output, environment, durable
  store, logs, tests, repository fixtures, cookie, or browser storage contract.
- Tests use a disposable trusted workspace and freshly generated/enrolled
  identities. The repository-root `.proof` identity and any historically
  exposed key are rejected as fixture, signer, authenticator, or verifier.
- Only Gate-B-approved dependencies change the manifest/lockfile; every public
  function has a unit test.
- Before product source fan-out, write only the root/member/dependency entries,
  complete auth package manifest, and the Gate-B-exact inert `src/lib.rs`
  scaffold required to give Cargo a target; define no item or behavior and run
  no Cargo, then signal `W3 root ready`. After E0002-05 signals
  `W3 kernel manifest frozen`, reconcile Cargo.lock alone with the exact frozen
  two-package offline check and signal `W3 lock stable`; only then may W3
  owners begin source edits. Because every auth Cargo command compiles its
  proof-kernel dependency, E0002-08 runs no post-fan-out Cargo command until
  E0002-05 signals source quiescence. W3 reverse-impact checks wait for all
