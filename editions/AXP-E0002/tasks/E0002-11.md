## Acceptance

- The process binds only exact IPv4 loopback, emits one clean non-secret URL,
  places no credential in URL/argv/output/environment/log, and shuts down before
  serving if workspace, listener, randomness, Human identity, or auth state is
  unsafe.
- The Gate-B-frozen signed-challenge state machine has one-use nonce issuance,
  exact Human/workspace/instance/requested-and-granted-capability/expiry binding,
  signature verification, replay resistance, generic failures, and one session
  publication winner. It imports no E0006 authority.
- Session establishment, protected routing, self-revoke, and app delivery share
  one exact origin. Mutations require exact Host, Origin, and JSON media; all
  responses have the frozen cache/content/frame/referrer/CSP boundary with no
  permissive CORS, cookie, service worker, or remote resource.
- A stable injected-router/static-source assembly interface is proven at W6
  with synthetic no-authority fixtures and without placing authority in HTML or
  static assets. W6 does not claim the downstream E0002-02/09 routes or
  E0002-03 app exist; actual composition is E0002-04/E0002-10 evidence.
- Control-plane restart/shutdown invalidates every volatile session and requires
  a fresh signed challenge. A runtime-worker restart while this process remains
  live preserves only the still-valid scoped session and durable run view.
- Deterministic process/Tower tests cover port/bind failure, concurrent/replayed/
  malformed/expired challenges, lost response, revoke/expiry, page reload,
  control-plane restart, runtime-worker restart, SIGINT/SIGTERM, and zero
  protected callback/provider/tool/external effect on failure.
- Only Gate-B-approved dependencies change root manifests; every public
  function has a unit test.
- `rtk cargo fmt --check -p proof-operator-control`,
  `rtk cargo test -p proof-operator-control`, and
  `rtk scripts/test-scoped.sh proof-operator-control` pass.
