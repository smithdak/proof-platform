## Acceptance

- Cancel is rechecked before model/provider dispatch, governed tool dispatch,
  and durable result commit; cancel-before-dispatch has zero provider/tool
  effect and one durable command/audit receipt.
- Approval remains a decision only. Resume explicitly claims the exact durable
  checkpoint; concurrent cancel/resume and duplicate resume have one winner and
  deterministic idempotent/conflict receipts.
- Recording-store barrier tests prove lease epoch/fence consumption, one-owner
  reclaim policy, stale-epoch dispatch/write rejection, and no result commit
  after authority loss. This task does not claim real SQLite restart behavior.
- Evaluator ordinal 067 is an explicit runtime recording-store acceptance
  obligation. A second `claim_run_lease(LeaseClaimRequest)` while the first
  lease remains active must be injected as
  `OperatorStoreError::NotActionable` rather than `Conflict`; the runtime must
  surface it at `OperatorRuntimeStage::ClaimLease`, preserve durable state and
  prior audit events with no new event, and record zero provider/tool/governed-
  write/external effect. The focused test must retain digest-only custody and
  prove that no raw lease token is exposed.
- Aggregate step/token/time/cost/tool budgets are reserved/committed atomically
  across concurrent runs and cannot overrun on failures or recovery.
- Barrier tests use deterministic fake providers/tools only and prove zero
  external effect.
- Synthetic adapter tests return exact boundary-usage reports; missing,
  wrong-kind, or over-ceiling reports consume custody through
  `result_invalid`, forfeit the full reservation, and never commit output.
- Runtime uses the injected kernel environment for monotonic/UTC checks and
  rechecks the immutable permit budget deadline immediately before handler
  entry; equality failure consumes custody through pre-effect settlement.
- Exact replay first calls `load_completed_replay` before budget reservation;
  after a deadline/capacity rejection it performs exactly one second lookup to
  observe a concurrently completed replay. Either hit returns the verified
  prior result with zero new reservation, permit, boundary call, or effect.
  Recording-store tests cover both lookups, exhaustion/deadline bypass, the
  concurrent-completion race, and corrupted-replay failure.
- E0002-14 is required before any protected mutation API may dispatch and owns
  the real runtime/SQLite/control restart and contention evidence.
- Preserve E0002-11's historical `W4 lock stable` signal before any W9 source edit or
  Cargo command. Local runtime format/unit checks may then run, but
  `rtk scripts/test-scoped.sh proof-agent-runtime` waits until every shifted W9 writer
  is quiescent so it cannot compile a peer's partial source.
- `rtk cargo fmt --check -p proof-agent-runtime`,
  `rtk cargo test -p proof-agent-runtime`, and
  `rtk scripts/test-scoped.sh proof-agent-runtime` pass.
