## Acceptance

- Public strict types exactly match frozen schemas and use canonical operation,
  version, ID, digest, time, and error conventions.
- Add the exact Gate-B-frozen GovernedEffectPolicy, PreparedHandlerMutation,
  PreparedHandlerOutput, GovernedExecutionPlan, PreparedApprovalBundle,
  PreparedReplayTransition, and PreparedGovernedExecution types; the two
  default-compatible OperationHandler methods; and
  ExecutionEngine::execute_evidenced_unpersisted with golden canonical
  serialization/digest tests for replay and non-replay branches.
- Add the kernel-owned OperatorSigner, complete store-built signing requests,
  transaction-borrowing replay decision seam, operator store traits, and
  RecordingOperatorControlStore. Governed execution performs no storage call
  and rejects ineligible or non-NoEffect handlers before any effect.
- Add the closed OperatorControlEnvironment/OperatorRandomPurpose seam and a
  deterministic recording fake; it owns trusted UTC, process monotonic ticks,
  purpose-tagged entropy, and generated UUIDv7 values without serializing them.
- Add the immutable OperatorSchemaCatalog constructor/binding/digest and
  read-only input/output validators. Its closed source inventory carries each
  normalized registry/input/output relative path plus exact raw bytes; the
  constructor strictly parses and cross-checks the registry itself and never
  reconstructs source bytes from parsed values. ExecutionEngine uses the
  injected Arc and no registry path or schema lookup occurs during governed
  execution.
- Freeze private prepared boundary-usage reporting: provider token/cost and
  tool zero/zero/one branches feed engine-owned PreparedUsage, are checked
  against the exact permit ceiling, and cannot be supplied by HTTP/store DTOs.
- Wait for E0002-08's `W3 root ready` signal, then add only
  `sha2.workspace = true`, `subtle.workspace = true`, and
  `zeroize.workspace = true` to the kernel package
  manifest and signal `W3 kernel manifest frozen` without running Cargo or
  editing source. Export narrow raw artifact SHA-256 and exact 32-byte
  constant-work comparison helpers; use zeroize for non-cloneable dispatch
  custody. Do not change the root manifest or lockfile.
- Cancel/resume command records, expected revisions, idempotent receipts,
  cursor bindings, lease/fence epochs, aggregate budget values, and append-only
  audit events have deterministic validation/transition tests.
- Conflict/error variants are specific and every new public function has a unit
  test. No new global `ExecutionError` variant is allowed unless the Gate B
  packet has explicitly added same-wave HTTP mapping ownership and tests.
- Wait for E0002-08's later `W3 lock stable` signal before any source edit or
  Cargo command. Local kernel format/unit checks may then run, but
  `rtk scripts/test-scoped.sh proof-kernel` waits until every W3 writer is
  quiescent so it cannot compile a peer's partial source.
- `rtk cargo fmt --check -p proof-kernel`, `rtk cargo test -p proof-kernel`, and
  `rtk scripts/test-scoped.sh proof-kernel` pass.
