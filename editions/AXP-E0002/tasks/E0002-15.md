  mounted route inventory has no legacy unauthenticated audit, proof,
  domain-list, generic operation, or fallback surface. Dependency direction is
  control-to-HTTP/storage/runtime only; no reverse control dependency or Cargo
  cycle is introduced.
- It opens only the Gate-B-frozen authoritative workspace database through the
  trusted opener, uses the persisted enrolled signer/identity lifecycle, and
  rejects alternate paths, ephemeral signer substitution, and repository-root
  `.proof` authority.
- Its build embeds the exact active registry/input/output schema catalog in a
  closed bytewise path inventory, preserving every normalized relative path
  and exact raw document. Provisioning stores that catalog digest; launch
  reconstructs it without parsed-value serialization, requires equality, and
  injects the same immutable Arc into the real store and execution engine
  before signer load.
- Implement the only released binary interfaces:
  `proof-operator-control init --workspace <absolute-path> --provision
  <absolute-path>`, and the sole released serving entrypoint,
  `proof-operator-control serve --workspace <absolute-path>`, by composing
  the storage-owned single-guard lifecycle. Every option occurs exactly once;
  serve always uses an OS-assigned port. The binary exposes no
  forbidden-path/trust option; both commands pass the mandatory
  path derived by taking two lexical parents from
  `Path::new(env!("CARGO_MANIFEST_DIR"))` and joining `.proof` in a nonempty
  path slice to storage for same-call descriptor comparison. Missing parents
  fail closed, the result has no `..` component, and there is no
  canonicalization or CWD/environment/argv fallback. Init creates no listener/effect,
  accepts no fallback or alternate database, and is tested for schema-13

  conflicting provision refusal, held-lock refusal, forbidden-identity
  refusal, and movement/sidecar failure before releasing the one descriptor.
- Init passes the stable provision/catalog request and same environment Arc to
  storage; process tests assert exact-existing retry consumes no new entropy or
  clock value and emits the persisted workspace identity.
- The real E0002-03 app is served from the same exact origin through the frozen
  static-source interface with no remote resource, embedded credential,
