## Stored shape and load semantics

The storage-local `StoredDelegationScopeV1` uses
`#[serde(deny_unknown_fields)]` and permits only:

```json
{
  "allowed_operations": ["release.publish"],
  "allowed_domains": ["content"],
  "resource_scope": "optional general resource boundary"
}
```

All three keys are optional for general backward compatibility; absent values
serialize as `{}`. `SqliteStore::save_delegation` persists legacy action and
resource arrays plus the complete structured scope. `SqliteStore` now
overrides `ExecutionStore::load_delegation` and returns `None` only when the
requested UUID has no row. A present row reconstructs every `Delegation`
field. Invalid stored row ID/issuer/recipient UUIDs, legacy list JSON,
structured JSON/type/unknown key, RFC3339 time, reversed validity window, or
non-boolean revocation integer returns a storage error and never falls back to
default scope.
