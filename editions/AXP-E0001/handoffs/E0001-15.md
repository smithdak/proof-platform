## Finding and repair

`cmd_import` previously inserted principals with an `ON CONFLICT` branch that
rewrote durable kind and public key. It also used the mutable delegation upsert
without first protecting an existing delegation ID, so an archive could
replace or un-revoke a stored grant. Finally, it saved each proof before
checking the signatures that followed and inserted principals after that loop,
allowing partial proof persistence before a later invalid signature.

Import now decodes and validates all principal IDs/Ed25519 keys, rejects
duplicates, and compares each enrolled principal's immutable kind/key. It
preflights delegation uniqueness, validity, issuer/recipient enrollment, and
exact equality for an existing ID. It then verifies every proof against the
enrolled or preflighted principal set before calling the canonical immutable
principal API or persisting any archive principal, proof, or delegation. The
delegation write itself is an immediate atomic conditional insert/exact no-op,
so a change after preflight is never overwritten. Exact principal and
delegation replay remains idempotent.

Regressions prove both kind and key replacement fail with the original
principal unchanged, a revoked delegation cannot be imported as active while
exact replay succeeds, and an invalid proof leaves both the preceding valid
proof and its previously absent imported principal unpersisted. Normal archive
round-trip and the newer-proof conflict rule remain green.

## Bounded scope

The general storage delegation API remains mutable for its existing callers;
signed, monotonic operator revocation is reserved for the next edition's
contract and migration work. Import of blobs, registry data, and workspace
files is still not one all-or-nothing transaction. E0001-15 closes only the
credential-adjacent identity/authority and proof-preverification hazards and
does not claim broader archive atomicity.

The repair did not open or mutate the retained readiness workspace. The later
completed-finish replay opened it through the trusted host path and left the
`0600` record immutable. No credential was read and no provider attempt, live
v2 run, artifact, failure, or charge was created.
