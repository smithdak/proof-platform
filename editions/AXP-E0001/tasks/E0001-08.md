# E0001-08 — CLI preflight and bounded live setup

- Wave: W4
- Model/reasoning: `gpt-5.6-sol` / high
- Risk and owner gate: critical credential/authority boundary; approved Gate B required
- Dependencies: E0001-01, E0001-02, E0001-03, E0001-06, E0001-07

## Objective

Make the CLI complete and verify the frozen deterministic Release Manager
preflight before reading any provider credential or constructing a provider.
Round-trip the complete operation-scoped delegation through grant, list,
validate, transfer, and live-agent setup, require the explicit grant ID, and
consume E0001-02's frozen deferred-gateway interface.

runtime/Content edit, proxy/failover, external deployment, or paid live attempt.

## Acceptance

- A deterministic failing preflight test proves `OPENAI_API_KEY` is never read
  and provider construction/request count remains zero.
- A passing path independently verifies the immutable deterministic evidence
  at 10/10 and validates the live policy's exact 17 unique declared check IDs,
  exact 20-vector set, template/check/tamper-set digests, and resolved bindings
  before credential lookup.
- Agent start/resume requires the exact persisted `delegation_id`; missing,
  revoked, expired, recipient-mismatched, unbounded, structured-resource,
  additional-operation/domain, or out-of-operation/domain grants fail before
  credential lookup and provider construction.
- Registering the CLI-owned gateway factory is credential-free. Only runtime
  invocation at the frozen boundary may read the key and build the HTTP
  gateway; start and resume spies prove every earlier failure invokes it zero
  times.
- Delegation CLI save/load/list/validate and transfer preserve the complete
  bounded scope added by E0001-07 without silently defaulting legacy data.
- Output and errors redact credentials and private identity material.
- CLI integration tests cover secret ordering and scope round trips.
- `rtk cargo fmt --check -p proof-transport-cli` passes.
- `rtk cargo test -p proof-transport-cli` passes.
- `rtk scripts/test-scoped.sh proof-transport-cli` passes after W4 quiesces.

## Stop and escalate

Stop if preflight cannot precede credential access without a public CLI change
outside the approved contract, or if scope persistence needs another crate
edit. Return the exact cross-owner request; never weaken the ordering.

## Handoff

Record command/API changes, preflight chronology, credential-read spy evidence,
delegation scope round trips, commands/results, redaction checks, and residual
risks. Do not include a credential or use a live provider.
