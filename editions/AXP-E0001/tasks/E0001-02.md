# E0001-02 — Provider continuation and fail-closed recovery

- Wave: W3
- Model/reasoning: `gpt-5.6-terra` / high
- Risk and owner gate: high; approved E0001-01 Gate B contract required
- Dependencies: E0001-01, E0001-06, E0001-07

## Objective

Implement the frozen provider-attempt and continuation contract in the leaf
runtime so restart, transient failure, and ambiguous completion cannot blindly
repeat a governed mutation or silently evade model-call/token/time/cost limits.
Persist the complete sealed request/tool/delegation/preflight binding required
for independent live-trace evaluation. Provide the additive credential-free
live setup and deferred gateway-factory seam consumed later by E0001-08.

## Non-goals

No kernel/storage/transport edit, migration, credential read, provider
failover, parallel tools, hosted tools, external deployment, or automatic
retry of an ambiguous state.

## Acceptance

- Persisted attempt/recovery tests cover request-before-call, successful
  response, transient pre-response failure, ambiguous completion, restart,
  approval wait/resume, and terminal sealing.
- The durable `dispatching` transition commits before any request byte can be
  written. A crash at every boundary proves only a certified zero-byte failure
  or the frozen no-response 429 case can enter the one-retry path.
- Attempts preserve requested/returned model, endpoint, process epoch, provider
  response ID, request/tool-set/schema digests, usage/pricing/cost, cumulative
  counters, retry linkage, delegation ID/scope digest, and preflight record.
- Existing runtime construction remains compatible. The new live path accepts
  the frozen credential-free setup, persists/re-reads the initial run binding,
  and invokes its deferred gateway factory only at the approved dispatch
  boundary; preflight/setup failures leave the factory invocation count zero.
- Live setup rejects before factory invocation every grant except the exact
  singleton `release.publish`/`content` scope, including default, wildcard,
  additional operation/domain, and any structured `resource_scope` value.
- The evaluator requires exactly the frozen 17 unique IDs and rejects missing,
  duplicate, added, reordered where relevant, or digest-mismatched check sets.
- The evaluator also binds and rejects drift in the exact ordered 20-vector
  tamper set and its digest.
- Exact retry limits and budgets survive restart; missing cost follows the
  approved fail-closed rule.
- No scenario dispatches or successfully persists the governed publication
  twice.
- Current deterministic Release Manager traces remain 10/10 and stable.
- `rtk cargo fmt --check -p proof-agent-runtime` passes.
- `rtk cargo test -p proof-agent-runtime` passes.
- `rtk scripts/test-scoped.sh proof-agent-runtime` passes after W3 quiesces.
