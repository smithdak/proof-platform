# E0001-03 — Durable local preview artifact

- Wave: W3
- Model/reasoning: `gpt-5.6-terra` / high
- Risk and owner gate: high; approved E0001-01 Gate B contract required
- Dependencies: E0001-01, E0001-06, E0001-07

## Objective

Implement the approved backward-compatible publication version and one
immutable, disposable local preview artifact bound to the exact requested
edition, environment, version, manifest digest, canonical output, and engine's
original proof.

## Writable paths (exclusive)

- `crates/proof-content/**`
- `registry/content/**`
- `editions/AXP-E0001/handoffs/E0001-03.md`

## Read-only references

- Approved E0001-01 contract, policy, decision, and handoff
- `contracts/domain-definitions.md`, `contracts/kernel-api.md`
- Current Content schemas, handler tests, release pipeline, and E0000 replay
  vectors

## Non-goals

No external deployment, production release, CMS adapter, storage migration,
kernel/transport edit, canonical content mutation before approval, or v1
breaking change.

## Acceptance

- Strict schemas reject unknown/missing identity, replay, edition, environment,
  version, and artifact fields according to the approved contract.
- The v2 registry row matches every frozen `RegistryEntry` field; v1 metadata,
  schema, handler behavior, output, and idempotency remain byte-compatible.
- First execution persists one artifact and returns the original engine proof;
  exact retry returns byte-equivalent output/proof with no second mutation;
  changed input conflicts before mutation.
- Artifact round-trip and independent proof verification bind all requested
  identifiers and digests. Tampered artifact/version/environment/manifest/proof
  tests fail.
- Nothing outside the disposable preview boundary changes before signed human
  approval; no test contacts an external target.
- `rtk cargo fmt --check -p proof-content` passes.
- `rtk cargo test -p proof-content` passes.
- `rtk scripts/test-scoped.sh proof-content` passes after W3 quiesces.

## Stop and escalate

Stop on a required migration, kernel/store/transport edit, external effect,
destructive cleanup, v1 break, or discrepancy with the approved replay/output
contract. Return a bounded Gate B request.

## Handoff

Record artifact schema/path/lifecycle, mutation counts, replay/proof/tamper
evidence, commands/results, residual risks, and cross-owner requests. Never
include private key or complete workspace contents.
