# E0001-17 — Workspace identity lifecycle integrity

- Wave: W12
- Model/reasoning: `gpt-5.6-sol` / high
- Risk and owner gate: critical credential-free signing-authority repair; no new live-use authority
- Dependencies: E0001-16

## Objective

Make every ordinary workspace-opening and key-rotation path bind the configured
actor exactly to the loaded signing key, reject linked config input, and prevent
initialization or rotation archival from silently replacing an identity.

## Writable paths (exclusive)

- `crates/proof-transport-cli/src/workspace.rs`
- `README.md`
- `editions/AXP-E0001/handoffs/E0001-17.md`

## Read-only references

- `contracts/kernel-api.md` immutable principal and proof actor contracts
- E0001-09 trusted preparation and E0001-14..16 identity/transfer evidence
- Existing workspace initialization, rotation, and private-mode tests

## Required repair

1. Harden and require a regular private config file before ordinary workspace
   use, then require its actor to equal the securely decoded keypair principal.
2. Reuse that exact invariant for the descriptor-relative preparation path.
3. Validate the actor/key binding before rotation creates an archive or changes
   config, key, or storage state; any mismatched or partial state fails closed.
4. Refuse reinitialization when either identity leaf already exists and create
   initial identity leaves with no-replace semantics.
5. Give every rotated-key archive a collision-resistant name and create it with
   no-replace semantics.

## Non-goals

No kernel/storage/schema/provider/runtime/Content/HTTP change, historical
workspace inspection, retained-readiness mutation, multi-file atomic rotation
protocol, automatic identity recovery, or live call. A crash between rotation's
individual identity-file writes may require operator recovery, but the
new open invariant must prevent signing from a partial state.

## Acceptance

- A distinct config actor makes ordinary open and rotation fail before any
  archive or identity-file mutation; exact config/key bytes remain unchanged.
- A symlinked config fails before workspace use.
- Reinitialization preserves the exact existing config/key and creates no
  rotation archive.
- Normal initialization, open, rotation, private-mode repair, and all prior CLI
  identity/import/live-preparation regressions remain green.
- All CLI targets compile; format, scoped diff, edition validation, complete
  host suite, and exact credential-free readiness replay pass.

## Stop and escalate

Stop on a required shared contract, migration, automatic destructive recovery,
credential boundary, retained packet mutation, provider use, or relaxation of
the fail-closed actor/signing-key invariant.

## Handoff

Record the original mismatched actor/signature and destructive reinitialization
paths, exact fail-closed behavior, preservation/compatibility evidence, residual
multi-file recovery scope, and final host/readiness results. Never record a
credential, private key, or copied database.
