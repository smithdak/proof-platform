# E0001-16 — Workspace archive extraction integrity

- Wave: W11
- Model/reasoning: `gpt-5.6-sol` / high
- Risk and owner gate: critical credential-free filesystem/authority repair; no new live-use authority
- Dependencies: E0001-15

## Objective

Make workspace import consume one immutable archive snapshot, reject path and
entry ambiguity before archive data persistence, bind every imported proof
file exactly to the verified manifest, and publish workspace JSON without
following target symlinks or hard links.

## Writable paths (exclusive)

- `crates/proof-transport-cli/src/commands/secure_fs.rs`
- `crates/proof-transport-cli/src/commands/transfer.rs`
- `crates/proof-transport-cli/src/main.rs`
- `editions/AXP-E0001/handoffs/E0001-16.md`

## Read-only references

- `contracts/kernel-api.md` proof and immutable principal contracts
- E0001-13 trusted-path and E0001-15 import-integrity evidence
- Existing export/import compatibility tests

## Required repair

1. Parse manifest and workspace-data entries from one open archive stream;
   reject missing/duplicate manifests and duplicate workspace filenames.
2. Reject parent, absolute, prefix, non-UTF-8, wrong-depth, non-regular, unsafe,
   and non-JSON workspace-data paths before archive-specific persistence.
3. Reject duplicate manifest proof IDs. Any workspace proof file must have the
   exact proof-ID filename and exact JSON value present in the manifest.
4. Replace workspace JSON through descriptor-relative directories and an
   atomic same-directory temporary-file rename. Never follow an existing
   symlink/hard-link leaf or symlinked subdirectory.
5. Add adversarial regressions for raw-tar parent traversal, symlinked target
   directories, absent/drifted proof bindings, and safe symlink-leaf replacement.

## Non-goals

No archive-format version, schema, kernel/storage API, provider, runtime,
Content, HTTP, historical-workspace, or retained-readiness mutation. Global
workspace JSON APIs, archive size policy, and all-or-nothing cross-database/CAS
transactions remain separately scoped.

## Acceptance

- A raw `workspace-data/../keypair.json` member fails before changing the
  private key file or durable principal count.
- A symlinked data subdirectory cannot write outside the workspace.
- An absent or byte-drifted workspace proof cannot bypass the signed manifest;
  no proof file or proof row is persisted.
- Existing symlink leaves are atomically replaced as leaves without changing
  their external targets; unsafe names fail.
- Normal archive round-trip, workspace-data restoration, newer-proof handling,
  and E0001-15 rejection paths remain green.
- All CLI targets compile; format, scoped diff, edition validation, and the
  complete host suite pass without weakening secure checks.

## Stop and escalate

Stop on a required archive-format/shared contract change, need to follow an
untrusted path, credential boundary, retained packet mutation, or provider/live
evidence.

## Handoff

Record the original traversal/two-open/symlink/proof-binding paths, exact
repair, adversarial and compatibility evidence, residual size/transactional
scope, and post-repair host/readiness results. Never record a credential,
private key, or copied database.
