# E0001-01 — Live journey contract and sealed evaluation

- Wave: W1
- Model/reasoning: `gpt-5.6-sol` / high
- Risk and owner gate: high; Gate A required to start, Gate B required to accept
- Dependencies: none

## Objective

Produce an owner-decidable, versioned contract and strict evaluation policy for
one live Release Manager preview journey. Resolve operation version,
idempotency, preview identity/artifact binding, provider-attempt recovery,
approval, budget/cost, and evidence semantics before implementation.

## Required decision packet

1. Compatibility matrix and recommended operation/version; do not break v1.
2. Canonical request, artifact, output, proof, idempotency, and replay shapes.
3. Persistent provider-attempt state machine with retryable versus ambiguous
   recovery and crash boundaries.
4. Strict policy schema/version, exact check and tamper-vector sets,
   policy/trace/request/tool digest binding, and live/deterministic separation.
5. Exact model-call/tool/token/time/cost limits and unknown-cost behavior.
6. Migration, shared API, authority, deferred provider construction, secret,
   and external-effect impact matrix.
7. Gate B recommendation, rollback, non-goals, and downstream task contract.

## Non-goals

Do not implement runtime/content behavior, call a provider, use credentials,
change a migration, deploy a preview, or weaken E0000 exact-replay rules.

## Acceptance

- Contract and policy are versioned, reject unknown fields by design, and have
  no unexplained mismatch with AXP, kernel, domain, registry, or implementation.
- Every material choice is either frozen or listed in one bounded Gate B packet.
- Downstream E0001-02/03/06/07/08 acceptance vectors can be implemented without
  hidden chat context or cross-owner API invention.
- Whitespace and final-newline checks explicitly inspect every changed and
  untracked packet file; ordinary `git diff --check` is not claimed for
  untracked paths.

## Stop and escalate

Stop on a required migration, operation removal/rename, v1 break, authority or
signature change, production/external effect, or a contract choice not bounded
by the charter. Return it in the Gate B packet; do not implement around it.

## Handoff

Record changed files, mismatch matrix, policy/check table, recovery state
machine, budget model, Gate B choices, risks, and commands in the matching
handoff. Never include credentials or `.proof` contents.
